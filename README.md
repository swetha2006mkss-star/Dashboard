Project Name: Hospital Management Dashboard

Short Description:
Hospital Management Dashboard is a web-based application that helps doctors and
administrators monitor and manage hospital activities efficiently. It provides a
centralized dashboard to view patient details, appointments, doctor availability, bed
status, medicine stock, and revenue information. The system helps in making quick
decisions by displaying important hospital data in an organized way.
